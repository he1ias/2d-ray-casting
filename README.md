# 2d raycaster made with HTML canvas

A 2d pixel raycaster made with HTML canvas for the Hack Club SHRINK event. Move your mouse around the webpage and see how your light interacts with the objects around you.

This demo was made to fit into under 3kb for the SHRINK event, however, code found in src/index.html is intended to be used in future in small 2d game projects.

To run, copy source of dist/uri.txt and paste it into the browser of your choice.
